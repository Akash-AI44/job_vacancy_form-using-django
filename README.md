# Job Vacancy Application Form

A simple web application built with Django where anyone can submit a job application by filling in their personal details and uploading their CV.

---

## What This Project Does

- Applicants can fill in a form with their **Name**, **Email**, **Address** and **CV**
- Submitted data is saved in the **database** (SQLite)
- Submitted data is also saved in a **JSON file** (`submissions/applications.json`)
- Uploaded CV files are stored in the `media/cvs/` folder
- Admin panel to view, search and manage all applications

---

## Technologies Used

- Python 3
- Django
- SQLite (default Django database)
- HTML
- JSON
